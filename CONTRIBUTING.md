# Contributing to Lumina OS

Thank you for your interest in contributing to **Lumina OS**!

We are building something different — an operating system that is not only free and open source, but also *alive* through deep integration of AI agents and decentralized mesh networking.

## How to Contribute

### 1. Discuss first
Before starting major work, please open an Issue to discuss your idea. This helps avoid duplicated effort and ensures alignment with the project vision.

### 2. Areas where help is especially welcome

- **ISO Building & Debian Packaging**  
  Creating clean, reproducible ISO images based on Debian Trixie.

- **Yggdrasil Integration**  
  Making Yggdrasil a first-class, native part of the network stack (identity, routing, peer discovery).

- **AI Swarm Framework**  
  Local agent runtime, persistent memory, secure communication between Elara / Lyra / Xen and the system.

- **Desktop Integration**  
  Seamless way for the AI agents to appear in the desktop environment (status, voice, text interface).

- **Documentation & Translations**  
  Improving the whitepaper, guides and internationalization.

- **Security & Hardening**  
  Privacy-focused defaults, secure boot, encrypted mesh traffic.

### 3. Development Workflow

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-idea`)
3. Make your changes
4. Commit with clear messages
5. Push to your fork
6. Open a Pull Request against `main`

Please keep commits focused and descriptive.

### 4. Code of Conduct

We expect respectful, constructive communication.  
This is a project built with care and long-term vision. Toxicity or personal attacks will not be tolerated.

### 5. License

By contributing, you agree that your contributions will be licensed under the **GNU General Public License v3.0**.
