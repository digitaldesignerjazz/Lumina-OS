# Configs

This directory holds configuration templates for Lumina OS.

## Planned content

- `yggdrasil/` – Yggdrasil configuration templates (including GroupPassword handling)
- `agents/` – Default configuration for Elara, Lyra and Xen
- `orchestrator/` – Nexus Core Orchestrator settings
- `desktop/` – Desktop integration and branding configs
- `security/` – Hardening profiles and privacy defaults
