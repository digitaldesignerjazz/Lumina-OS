# Scripts

This directory contains helper and build scripts for Lumina OS.

## Planned scripts

- `build-iso.sh` – Create a reproducible ISO image
- `prepare-yggdrasil.sh` – First-boot Yggdrasil identity setup
- `setup-agents.sh` – Initialize the AI Swarm (Elara, Lyra, Xen)
- `update-mesh-peers.sh` – Manage public and private Yggdrasil peers

Scripts will be added as development progresses.
